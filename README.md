# 📦 전개도 마스터 — 펼치고 접어보는 전개도

**기초제도 Ⅲ. 제도의 기본 도법 — 5. 전개도 그리기** 단원용 학습·수업 보조 도구입니다.
설치 없이 브라우저에서 바로 실행되며, HTML 파일 하나로 오프라인·휴대폰에서도 작동합니다.

## 왜 만들었나

전개도는 "펼친 그림"이라는 말로는 잘 와닿지 않고, 종이를 직접 오려 접어보지 않으면 이해가 어렵습니다.
이 도구는 **슬라이더 하나로 전개도가 실제로 접혀 입체가 되는 과정**을 보여 줍니다.
모든 접힘은 실제 3차원 회전으로 계산되며, 접었을 때 오차 없이 정확히 닫히도록 검증했습니다.

## 구성

| 모드 | 내용 |
|------|------|
| 📖 **펼쳐보기** | 입체 8종을 슬라이더로 펼치고 접기. 전개도법·전개 치수 공식 표시 |
| **도전 ①** 전개도법 | 입체를 보고 평행선법·방사선법·삼각형법 고르기 (교과서 평가 06번 유형) |
| **도전 ②** 전개도→입체 | 펼쳐진 전개도를 보고 어떤 입체가 될지 맞히기 |
| 🎯 **종합시험** | 두 유형을 섞어 10문항 출제 후 **결과 제출** |

## 수록 입체와 전개도법

| 입체 | 전개도법 | 핵심 |
|------|----------|------|
| 정육면체 · 사각기둥 · 삼각기둥 · 육각기둥 | **평행선법** | 모선이 서로 평행 |
| 원기둥 | **평행선법** | 옆면 전개 = 가로 **πd** × 세로 h |
| 사각뿔 | **방사선법** | 모선이 한 꼭짓점에 모임 |
| 원뿔 | **방사선법** | 부채꼴 중심각 = **360° × r / ℓ** |
| 편심 원뿔(깔때기) | **삼각형법** | 면을 삼각형으로 분할 |

> 원기둥·원뿔은 "각의 수가 아주 많은 각기둥·각뿔"로 만들어, 각기둥에서 원기둥으로 자연스럽게 이어지도록 했습니다.
> 육각기둥 → 원기둥 순서로 보여 주면 "왜 원기둥 옆면이 직사각형이 되는지"를 설명하기 좋습니다.

## 수업에서 쓰는 법

- **수업 자료**: `펼쳐보기`에서 입체를 고르고 `▶ 접기 애니메이션`으로 시연. 각기둥과 뿔을 번갈아 보여 주면 평행선법·방사선법의 차이가 한눈에 들어옵니다.
- **형성평가(제출)**: 주소 뒤에 `?rc=<Apps Script URL>` 을 붙여 배포하면, 종합시험 종료 시 학생이 **반·번호**를 넣어 제출하고 결과가 구글 시트에 모입니다.
  ```
  .../전개도-master/?rc=https://script.google.com/macros/s/.../exec
  ```
